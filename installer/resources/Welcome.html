MK Crossfader

MK Crossfader was created for live performance with Maschine 3 on macOS and Maschine+ hardware in Controller mode. This package installs two independent tools:

  • MK MIDI Crossfader, a native macOS menu-bar app.
  • MK Crossfader VST3, a self-contained Controller and Target plug-in.

Both tools also work with Ableton Live. The VST3 does not require the app to be installed or running.
