Installation details

The installer places files in these locations:

  • /Applications/MK MIDI Crossfader.app
  • /Library/Audio/Plug-Ins/VST3/MK Crossfader.vst3
  • /Library/Application Support/MK Crossfader

The app and VST3 are independent products. Either can be used by itself; neither needs the other to be installed or running.

MK Crossfader was designed around Maschine 3 with Maschine+ hardware in Controller mode. Both tools also work with Ableton Live and accept any MIDI controller that sends a standard, assignable MIDI CC.

Neither tool runs inside Maschine+ in standalone mode.

Close Ableton Live, Maschine 3, and other plug-in hosts before installing. Restart or rescan the host after installation.

The package contains no installer scripts. It does not create an account, contact a server, or collect analytics.
